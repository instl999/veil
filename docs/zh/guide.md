# veil 新手分步指南

本指南不需要任何技术基础。请按顺序完成各部分。灰色框中的内容需要输入或粘贴——
请直接复制，不要手动重新输入。**粗体**表示需要点击的按钮或菜单项。

第一次大约需要一小时，大部分时间在等待 Cloudflare 和 VPS 服务商。安装脚本会
引导你完成每一项设置，并和你一起逐项检查。

本指南中用以下虚构的值代替你自己的信息：

| 指南中的示例 | 代表 |
|---|---|
| `203.0.113.10` | 你的服务器 IP 地址 |
| `www.example.com` | 你的 **站点域名**（第一个域名） |
| `static.example.net` | 你的 **CDN 域名**（第二个域名） |
| `you@example.com` | 你的邮箱 |

---

## 最终效果

- 一台租用的境外小服务器（"VPS"），为你转发网络流量。
- 在任何人看来，它只是一个使用真实证书的安静的摄影博客。
- 每台设备（电脑、手机、路由器）上装一个应用，像 VPN 一样开关；三条线路
  会自动互相接替。
- 维护、安全更新和备份每晚自动运行；需要你处理时，手机会收到提醒。

## 第 1 部分 —— 需要准备什么

| 项目 | 获取途径 | 费用 |
|---|---|---|
| 一台 **Debian 12**（或 Ubuntu 22.04/24.04）VPS，KVM 类型，有独立公网 IPv4 | VPS 服务商（第 2 部分） | 约 $5–11 / 月 |
| **两个**互不相关的域名 | 任意注册商（Namecheap、Porkbun、Cloudflare……） | 每个约 $2–10 / 年 |
| 一个免费的 Cloudflare 账号 | <https://dash.cloudflare.com/sign-up> | 免费 |
| 一个邮箱 | — | — |
| 一台 Windows 或 Mac 电脑，以及你的手机 | — | — |

**为什么要两个域名？** veil 有一条经过 Cloudflare 的备用线路（"CDN 线路"），
即使你的网络封锁了服务器 IP 也能继续使用。如果两条线路共用一个域名，看到这两个
名字的人就能知道它们属于同一台服务器。便宜的域名（`.xyz`、`.top`、`.click`）
完全可以。不要使用带有 *proxy*、*vpn*、*ss* 字样的名字。

一开始只有一个域名也可以：CDN 线路是可选的，之后随时可以添加（`veil` →
**更换 CDN 域名**）。

## 第 2 部分 —— 租用 VPS

1. 选择至少 **1 GB 内存**、每月流量充足（1 TB 比较宽裕）的套餐。如果商家提到
   **CN2 GIA**、**9929** 或 **CMIN2**，这些线路从中国大陆访问更快。
2. 操作系统选择 **Debian 12**。
3. 付款后你会收到（邮件或商家面板中）：
   - 服务器的 **IP 地址**，如 `203.0.113.10`；
   - **root 密码**。

   请把两者保存在安全的地方（最好用密码管理器）。

如果商家面板有 **防火墙** 或 **安全组**，先不用管——安装脚本会告诉你具体要放行
哪些端口（第 9 步）。

---

## 第 3 部分 —— 把域名添加到 Cloudflare

**每个**域名都做一遍：

1. 登录 Cloudflare → **添加域 / Add a domain** → 输入域名 → 选择 **Free（免费）**
   套餐。
2. Cloudflare 会显示两个 **名称服务器 / nameservers**（如 `ada.ns.cloudflare.com`）。
   到你购买域名的注册商处找到 **Nameservers**，选择自定义，把原有的替换成这两个。
3. 等待 Cloudflare 发邮件通知域名已 **生效 / Active**（几分钟到几小时）。

现在只需要做这些。DNS 记录和安全设置会在安装过程中完成，安装脚本会告诉你点击
哪里，然后自动检查。

## 第 4 部分 —— 登录服务器

### Windows

1. 按 **Windows 键**，输入 `powershell`，按 **回车**。
2. 输入（换成你的服务器 IP）：

   ```
   ssh root@203.0.113.10
   ```

3. 第一次会问 *Are you sure you want to continue connecting?* —— 输入 `yes`
   并回车。
4. 输入 root 密码。**输入时屏幕上不会显示任何字符，这是正常的。** 按回车。

提示符会变成类似 `root@server:~#` 的样子，说明你已经在服务器上输入命令了。

### Mac

打开 **终端 / Terminal**（⌘ + 空格，输入 `Terminal`，回车），然后执行上面第 2–4 步。

### 可选：用密钥代替密码登录

密码登录会一直保留（Fail2ban 会拦截猜密码的人）。如果你更想用密钥，在 GitHub
上把本仓库下载为 ZIP（**Code → Download ZIP**），解压后在 Windows 上双击
**`tools\setup-ssh-key.cmd`**。它会询问服务器 IP，把新密钥复制到服务器（你只需在
ssh 自己的提示中输入一次密码），之后 `ssh veil-vps` 即可免密码登录。

如果商家给你的是非 root 用户，登录后先运行 `sudo -i`。

## 第 5 部分 —— 安装 veil

在服务器上粘贴下面这一行并回车：

```
curl -fsSLO https://github.com/instl999/veil/releases/latest/download/veil-install.sh && bash veil-install.sh
```

在浏览器中打开 Cloudflare 控制台，放在终端旁边。安装脚本会用中英文带你完成
**11 个步骤**。在任何问题处都可以按 **Ctrl+C** 退出，之后重新运行
`bash veil-install.sh` 即可——不会造成任何损坏。

| 步骤 | 安装脚本询问或显示的内容 | 你需要做的 |
|---|---|---|
| **1. 开始之前** | 需要准备的东西、服务器 IP | 按回车 |
| **2. 站点域名** | 需要创建的 DNS 记录 | 在 Cloudflare 打开 **第一个** 域名 → **DNS → 记录 → 添加记录**：类型 **A**，名称 **www**，IPv4 填服务器 IP，代理状态 **仅 DNS（灰色云朵）** → **保存**。然后输入完整名字（`www.example.com`）。安装脚本会检查；如果还没生效，等一分钟后按 **回车** 重新检查 |
| **3. 备用线路** | 是否设置 CDN 线路，以及需要在 Cloudflare 完成的四项 | 按回车（是），然后在 **第二个** 域名中：**a)** 添加记录 **A**，名称 **static**，你的 IP，**已代理（橙色云朵）**；**b)** **SSL/TLS → 概述 → 配置 → 完全（严格）/ Full (strict)**；**c)** **SSL/TLS → 源服务器 → 创建证书** → 保持默认 → **创建**，保持该页面打开；**d)** **SSL/TLS → 源服务器 → Authenticated Origin Pulls：开启**。输入 CDN 域名（`static.example.net`）。证书选择 **1**，先粘贴 **源证书 / Origin Certificate** 框的内容，再粘贴 **私钥 / Private Key** 框的内容（Windows 如果提示粘贴多行，选择 **仍然粘贴**） |
| **4. 邮箱** | 用于证书通知的邮箱 | 输入你的邮箱 |
| **5. 选项** | Hysteria2（UDP 快速线路）、先安装系统更新 | 按两次回车（是、是） |
| **6. 提醒** | 如何在手机上接收故障提醒 | 选择 **1**（ntfy）：安装免费的 **ntfy** 应用，点 **+**，订阅屏幕上显示的主题名，然后按回车。iPhone 用户如果希望在国内也能收到，可以选 **2**（Bark） |
| **7. 确认** | 汇总信息，以及自动开启的防护 | 按回车开始安装，需要 3–10 分钟 |
| **8. 全面检查** | 每一项检查的结果（OK 或修复方法） | 如果有标记为 **XX** 的项目，按提示处理后按回车重新检查。还会确认 Authenticated Origin Pulls 并发送测试提醒——回答是否收到 |
| **9. 服务商防火墙** | 需要放行的端口 | 仅当商家有防火墙面板时：放行这些端口 |
| **10. 设备** | 每台设备的订阅链接和导入方法 | 输入设备名（如 `shadowrocket`）显示二维码，或直接回车 |
| **11. 备份** | 备份文件及复制命令 | 把它复制到你的电脑（见下文） |

如果最后提示需要重启，按回车，一分钟后重新登录即可。

### 把备份复制到你的电脑（第 11 步）

安装脚本会打印类似下面的一行。请 **在你的电脑上** 运行——新开一个 PowerShell
或终端窗口，不要登录服务器：

```
scp root@203.0.113.10:/root/veil-backup-20260101-120000.tar.gz .
```

文件会保存到该窗口所在的文件夹（通常是你的用户文件夹）。它包含你的密钥：请私密
保存，例如放在密码管理器或加密盘中。有了它，15 分钟就能迁移到新服务器，设备无需
任何改动。

## 第 6 部分 —— 配置设备

从官方页面自行安装应用，然后导入 **该设备自己的订阅链接**（每台设备都有自己的
链接，因为每台设备模仿的是它自己的浏览器）。在服务器上，`veil` → **1** 显示链接，
**2** 显示二维码。

| 设备 | 应用 | 导入方法 |
|---|---|---|
| Windows、Mac | [Clash Verge Rev](https://github.com/clash-verge-rev/clash-verge-rev/releases) | **订阅** → 粘贴 `windows` 或 `mac` 链接 → **导入** → 点击该订阅。然后 **设置 → 系统代理**（仅浏览器）或 **TUN 模式**（所有应用） |
| 安卓（也支持 Windows/Mac/Linux） | [FlClash](https://github.com/chen08209/FlClash/releases) | `veil` → **3. 添加设备** → 指纹选 **android**，客户端选 **flclash** → 用手机相机扫描二维码 |
| iPhone、iPad | Shadowrocket（付费，非中国区 App Store） | `veil` → **2** → `shadowrocket` → 在 Shadowrocket 中扫描。然后 **设置 → 订阅 → 自动更新：开启**——必须开启，因为密码每月更换 |
| 路由器（OpenWrt） | OpenClash | **配置订阅 → 添加** → `router` 链接，开启自动更新；Meta 内核；Fake-IP 模式 |

各应用的详细说明：[clients.md](clients.md)。

**一台设备上同一时间只运行一个代理或 VPN 应用。**

## 第 7 部分 —— 日常使用

- 需要时打开应用。国内网站不会经过服务器，所以一直开着也没问题。
- 应用每 12 小时自动更新订阅；凭据更换和改进会自动生效。
- 服务器每晚自动续期证书、每月更换密码、安装更新（需要时在北京时间 06:00 重启）、
  备份并自检。出现问题时，手机会收到提醒。

### `veil` 菜单

登录服务器后输入 `veil`：

| 你想要…… | 选择 |
|---|---|
| 查看订阅链接 / 二维码 | **1** / **2** |
| 添加或删除手机、平板、电脑 | **3** / **4** |
| 链接泄露了——生成新链接 | **5** |
| 检查一切是否正常 | **6. 全面检查** |
| 修改提醒、轮换、升级设置 | **8. 设置** |
| 生成备份并复制到电脑 | **11. 备份** |
| 更新 veil | **15** |
| 退出 | **0**，然后输入 `exit` 退出登录 |

所有菜单项和命令：[operations.md](operations.md)。

## 第 8 部分 —— 出现问题时

先登录服务器并运行：

```
veil doctor
```

它会检查所有项目，并为每个问题给出解决方法。常见情况：

| 现象 | 处理方法 |
|---|---|
| **Shadowrocket** 中 `HY2` 不显示延迟，但选中后可以上网 | 正常——Shadowrocket 的延迟测试测不了 Hysteria2。能打开网页就说明正常。 |
| `HY2` 不显示延迟或超时 | 部分网络晚上会限制 UDP，属于正常。应用会自动切换到 `REALITY` 或 `CDN`。 |
| 家里完全不能用，但手机流量可以 | 家里的线路可能封锁了服务器 IP。`CDN` 线路仍然可用，确认应用使用了它。然后准备迁移（[backup.md](backup.md)）。 |
| `ssh` 连不上 | 换手机流量试试。密码输错 5 次会被封禁一小时——等待，或使用商家的网页控制台。 |
| 安装脚本报错停止 | 阅读提示信息，修复原因后重新运行 `bash veil-install.sh`，可以安全重复运行。 |

其他问题：[troubleshooting.md](troubleshooting.md)。

## 第 9 部分 —— 保持安全

以下事项只能由你来做，其余都是自动的（见 [security.md](security.md)）：

- 订阅链接请勿外泄。如果泄露：`veil` → **5**。
- 把备份文件私密地保存在你的电脑上。重大修改后重新备份（`veil` → **11**）。
- 保持提醒开启（`veil` → **8**），并在 Shadowrocket 中开启自动更新。
- 保持第 3 步的 Cloudflare 设置：站点域名为灰色云朵；CDN 域名为橙色云朵、
  完全（严格）并开启 Authenticated Origin Pulls。
- 如果商家有防火墙面板，只放行第 9 步列出的端口。

## 名词解释

| 名词 | 含义 |
|---|---|
| VPS | 数据中心里租用的小服务器 |
| SSH | 在服务器上安全输入命令的方式 |
| DNS 记录 | 告诉互联网某个名字对应哪个 IP |
| 灰色 / 橙色云朵 | Cloudflare 中：名字直接指向你的服务器 / 经过 Cloudflare 转发 |
| 订阅链接 | 应用读取配置的秘密网址 |
| REALITY / HY2 / CDN | 三条线路：主线路（TCP）、快速线路（UDP）、备用线路（经 Cloudflare） |
| Fail2ban | 自动封禁反复猜 SSH 密码的电脑 |
| BBR | 服务器的网络加速设置 |
| 源服务器证书 | Cloudflare 签发的证书，用于向 Cloudflare 证明你的服务器身份 |
| Authenticated Origin Pulls | Cloudflare 向你的服务器证明自己的身份，这样服务器对 CDN 域名只响应 Cloudflare |
